# KenwenLeetCodeSolution

> Historical Java algorithm-practice repository, preserved for reference.

The main `leetcode` module contains personal LeetCode and Coding Interviews solutions with JUnit-based exercises. The `code` module contains supporting implementations of arrays, linked lists, trees, sorting algorithms, concurrency patterns, and Java language experiments; `app` is an Android host module from the original workspace.

## Status

- Java source compatibility: Java 8.
- Original Android build stack: Android Gradle Plugin 4.2.2.
- The repository is no longer presented as a daily-updated solution set.
- The build has not been revalidated with current Android Studio, Gradle, JDK, or Android SDK versions.
